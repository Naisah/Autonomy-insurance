# Autonomy Insurance

Life insurance communication system: Chat with Agent, policy estimates, claims, AI chatbot, and a separate Rewards app. Web (React) and mobile (Flutter) share one account.

Built spec-first. Start with:
- specs/00-constitution.md: decisions, stack, schedule
- specs/README.md: index and status of every spec
- AGENTS.md: rules for coding agents
- design/README.md: Stitch screens and design tokens

Course: ITS120P.
